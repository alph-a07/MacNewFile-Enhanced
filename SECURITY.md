# Security Policy

## Supported Versions

MacNewFile Enhanced is actively maintained. Security patches are applied to the latest release line.

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| < 3.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of MacNewFile Enhanced very seriously. Because MacNewFile interacts directly with macOS Finder, file system operations, and external editor applications, maintaining a safe and sandboxed execution model is paramount.

If you discover a security vulnerability or potential threat:

1. **Do not open a public issue.**
2. Send a report via GitHub Security Advisories at:
   **[https://github.com/alph-a07/MacNewFile-Enhanced/security/advisories/new](https://github.com/alph-a07/MacNewFile-Enhanced/security/advisories/new)**
   Or contact maintainers privately via GitHub.

### When submitting a report, please include:

- Description of the potential vulnerability.
- Steps to reproduce or proof-of-concept script.
- macOS version and hardware architecture (Apple Silicon / Intel).
- Potential impact and suggested mitigations (if known).

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Once verified, a patched release will be published along with full disclosure credits.
